Pega el token de GitHub

Se pide una sola vez en este navegador. Queda cifrado con tu contraseña y nunca se publica en el sitio.

  1. Entra a GitHub → Fine-grained tokens.
  2. En Repository access elige Only select repositories → TIENDA.
  3. En Permissions → Contents elige Read and write. Genera el token y pégalo aquí.
